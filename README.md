# Finastech

Um projeto desenvolvido de financias coletivas para viagens.

## Um exemplo

Para ajudar grupos de pessoas(como amigos, familiares, conhecidos, etc...) a gerenciarem gastos compartilhados e planejar orçamento em conjunto.

## O que tem dentro?

Usamos html, css, bootstrap 4, javascript, TypeScript, SCSS, Stylus, Less.

### Apps and Packages

- `HTML5`: Estruturação semântica de toda a aplicação
- `Bootstrap 4 e CSS3`: Utilizados para o design da interface, garantindo total adaptabilidade.(responsividade) para diferentes tamanhos de tela (celulares, tablets e computadores).
- `JavaScript`: Lógica de negócios e dinamismo das interações.
- `TypeScript`: utilizado para gerir no backend.

### Como executar o projeto?

Para rodar o aplicativo, entre na raiz do backend/ e rode:

```bash
npm run build
npm run start
```
